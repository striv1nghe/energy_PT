## 一、通用说明

### 1.1 基础信息

| 配置项 | 说明 |
|---|---|
| **正式环境 Base URL** | `http://bd01.bbicloud.com:9001` |
| **请求协议** | HTTP / HTTPS |
| **请求方法** | POST |
| **数据传输格式** | `Content-Type: application/json; charset=UTF-8` |

### 1.2 认证鉴权（Token）

接口调用采用 JWT（JSON Web Token）鉴权机制。调用方需在请求头 `token` 中携带有效签名凭证。
- **签名算法**：JwtToken 标准算法
- **Payload 必填字段**：
  - `Subject`: 主体标识
  - `Issuer`: 签发机构标识

### 1.3 通用请求头（Header）

除数据推送接口外，主动调用的 API 均需在 HTTP 请求头中传入以下公共参数：

| 参数名称 | 类型 | 是否必填 | 描述 | 示例值 |
|---|---|:---:|---|---|
| `token` | String | 是 | JWT 加密认证令牌（需包含 Subject 与 Issuer） | `eyJhbGciOiJIUzI1NiIsIn...` |
| `projectId` | Long | 是 | 项目标识 / 项目编号（本项目真实 ID） | `202607020000000001` |

### 1.4 通用返回结构

所有业务接口均返回标准 JSON 响应结构：

```json
{
  "code": 0,
  "status": 0,
  "msg": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 描述 |
|---|---|---|
| `code` | Integer | 返回码，`0` 表示调用成功，非 `0` 表示业务异常 |
| `status` | Integer | 状态标识码，`0` 表示操作成功 |
| `msg` | String | 返回结果提示或错误描述信息 |
| `data` | Object / Array | 业务响应数据实体，不同接口返回结构不同 |

### 1.5 错误码

| 返回码（code） | 描述（msg） | 说明 |
|---|---|---|
| `0` | 操作成功 / 接口调用成功 | 业务执行成功，详情请参考具体接口 `data` |
| `20001` | 表计已存在召测任务 | 当前电表有尚未完成的抄表任务，请勿重复触发 |

### 1.6 状态字典对照

#### 继电器状态（jdqzt）
| 编码值 | 状态定义 |
|---|---|
| `00120001` | 合闸（通电状态） |
| `00120002` | 拉闸（断电状态） |

## 三、表计数据查询

### 3.1 接口信息

- **接口描述**：查询指定电表在特定时间范围内的历史采样及冻结数据。
- **请求方式**：`POST`
- **接口路径**：`/iot/data/queryMeterData`
- **完整 URL**：`http://bd01.bbicloud.com:9001/iot/data/queryMeterData`

| 参数 | 类型 | 是否必填 | 描述 |

## 四、远程抄表（实时召测）

- **请求方式**：`POST`

| 参数 | 类型 | 是否必填 | 描述 |
|---|---|:---:|---|

### 4.3 请求参数（Body）

| 参数 | 类型 | 是否必填 | 描述 | 示例值 |
|---|---|:---:|---|---|
| `meter_no` | String | 是 | 目标电表编号 | `292606300049` |

#### 请求体示例

```json
{
  "meter_no": "292606300049"
}
```

### 4.4 响应参数

| 参数 | 类型 | 描述 | 示例值 |
|---|---|---|---|
| `code` | Integer | 业务状态码，`0` 为成功 | `0` |

| ├─ `task_id` | String | 异步召测任务 ID，用于查询最终抄表结果 | `u3ndfi81hkjvjp1070akrj4cis` |
| └─ `meter_no` | String | 目标电表编号 | `292606300049` |

#### 响应体示例

```json
{
  "code": 0,
  "status": 0,
  "msg": "操作成功",
  "data": {
    "task_id": "u3ndfi81hkjvjp1070akrj4cis",
```

## 五、远程拉闸（断电控制）

### 5.1 接口信息

- **接口描述**：对指定电表下发远程断电（拉闸）控制指令。该接口为异步触发，成功下发后返回控制任务 `task_id`。
- **请求方式**：`POST`
- **接口路径**：`/iot/disconnectMeter`
- **完整 URL**：`http://bd01.bbicloud.com:9001/iot/disconnectMeter`

### 5.2 请求头（Headers）

| 参数 | 类型 | 是否必填 | 描述 |

## 八、BBICloud Web 直连数据通道（备用/免Token方案）

### 8.1 方案概述与鉴权说明

### 8.7 本地 SQLite 三级同步工具使用指南

仓库内置了 [sync_energy_to_sqlite.py](file:///Users/byte/Documents/GitHub/energy_PT/sync_energy_to_sqlite.py)，支持三级采集与统一写入本地 SQLite 数据库（`energy_data.db`）：

1. **第一级（天级 Daily Freeze）**：每天查询一次全量电表日冻结数据（存入 `meter_readings` 表）。
   ```bash
   python3 sync_energy_to_sqlite.py --mode daily
   # 或者指定回溯天数：
   python3 sync_energy_to_sqlite.py --mode daily --days 7
   ```

2. **第二级（15分钟级 Load Sample）**：每 15 分钟查询一次电表最新负荷采样与设备工况（存入 `meter_load_samples` 表）。
   ```bash
   python3 sync_energy_to_sqlite.py --mode sample
   ```

3. **第三级（分钟级 Sudden Alarm）**：每 1 分钟轮询一次突发告警事件（存入 `alarm_events` 表）。
   ```bash
   python3 sync_energy_to_sqlite.py --mode alarm
   ```

4. **单次全量对齐**：
   ```bash
   python3 sync_energy_to_sqlite.py --mode all
   ```

5. **内置常驻守护进程（Daemon 模式）**：
   自动按照「告警每60秒、负荷采样每15分钟、日冻结每日凌晨」自主调度拉取：
   ```bash
   python3 sync_energy_to_sqlite.py --daemon
   ```

6. **查看数据库当前统计概览**：
   ```bash
   python3 sync_energy_to_sqlite.py --summary
   ```
